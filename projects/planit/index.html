iOS · API integration

One clear view of what is due next.

PlanIt brings Canvas deadlines and manually created tasks into a focused mobile experience.

PlatformiOS
ToolsSwift, Canvas API
FocusInformation clarity

01 · Problem

Deadlines were scattered across Canvas.

The issue was not a lack of task apps. It was the effort required to discover what mattered across multiple Canvas surfaces before productive work could begin.

02 · Approach

Make external data feel native.

PlanIt was designed to retrieve upcoming assessments through the Canvas API while still supporting manually created tasks and events. The interface prioritised upcoming work rather than reproducing the complexity of the source system.

03 · Learning

Integration design is information design.

The project developed my understanding of API-driven products, local persistence and the importance of transforming source data into a useful user model.
